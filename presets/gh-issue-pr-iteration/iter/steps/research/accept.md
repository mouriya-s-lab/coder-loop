# Acceptance: research

## Required report fields

The report must contain: `Why I approached it this way`; `What I actually found` with a per-question conclusion + cited evidence (verbatim quotes where exact wording matters); `Problems`. Structurally incomplete → send back the missing fields before judging substance.

## Judgment

Judge the research report against:

- **Coverage** — every question in the dispatched `Step focus` has either a conclusion or an explicit can't-answer with what was tried. Unaddressed questions are gaps.
- **Evidence** — each conclusion cites checkable evidence (`path:line`, command output, refs). A conclusion phrased from memory or plausibility ("usually", "should be") without a repo observation is a gap.
- **No silent scope creep** — the subagent reported, not solved, adjacent discoveries.
