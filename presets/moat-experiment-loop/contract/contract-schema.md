# ExperimentPacket schema

Publish one current marker containing: issue and run identities; hypothesis; fixed assumptions; environment and version identities; prerequisites and linked IaC children; ordered prepare/deploy/experiment/export/restore/writeback commands; acceptance matrix with passed/failed/inconclusive observations; evidence/manifest paths; cleanup ledger requirements; run PR and owning design destination; packet timestamp and source links. Supersede older markers explicitly without editing their history.
