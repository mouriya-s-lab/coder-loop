# GitHub routing

The experiment issue owns problem, hypothesis, acceptance matrix, dependencies, and terminal meaning. The draft run PR owns phase handoffs, raw evidence/findings diff, checks, and review discussion. The owning design PR owns the durable design conclusion. Before a run PR exists, discuss ambiguity on the issue; afterwards, phase and review feedback belongs on the run PR. Every mentioned issue or PR must use a URL. Read full timelines and checks before acting.
