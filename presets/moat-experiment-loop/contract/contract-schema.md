# ExperimentPacket schema

Publish one current marker containing: issue and run identities; hypothesis; fixed assumptions; environment and version identities; prerequisites and linked IaC children; ordered prepare/deploy/experiment/export/restore/writeback commands; acceptance matrix with passed/failed/inconclusive observations; evidence/manifest paths; cleanup ledger requirements; run PR and owning design destination; packet timestamp and source links. The packet must not declare volatile live-state bindings — current run head, next mode/phase, or live child/PR state; git, the engine, and live GitHub are their sole authorities, and consumers must not require such bindings. Immutable commit references are provenance only, never a currentness assertion. Supersede older markers explicitly without editing their history.
