## 角色分工

- **主 session（Claude）**：规划（划分方案、每轮范围、验收标准）、对 codex 产出逐段实质审读并提出具体修改意见、commit。规划不外包。
- **codex subagent**（codex:codex-rescue，默认模型）：读材料文件对齐认知、对主 session 的规划提出对抗性异议、按定稿范围执笔改 A.md。顺从是失职。

## 轮次计划

1. **划分对抗**（≥2 轮）：codex 对 division-plan.md 提异议 → 主 session 回应/修订 v2 → 再对抗 → 定稿 commit。
2. **总纲修订**（≥2 轮）：以主 session 四点审读意见（见 TaskList #2 描述）+ 定稿划分为输入，codex 修订 A.md 第 0 篇 → 主 session 逐段审 → 再改 → commit。
3. **逐面重写**（每面 ≥2 轮，面的清单以定稿划分为准）：每面 = codex 初稿 → 主 session 逐段实质审读给具体意见 → codex 第二轮修改 → 主 session 复核 → commit。每轮只改该面的一部分时可以更多轮。
4. **收尾对账**（≥2 轮）：跨面去重、依赖方向检查、旧编号映射表、删除残留冲突表述。
